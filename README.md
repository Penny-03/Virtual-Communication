# Virtual Communication — Pixel City

**An interactive virtual city exploring avatar-based interaction and digital communication.**

## Project Overview

Virtual Communication is a web-based prototype developed during my Erasmus+ exchange at Universitat Pompeu Fabra in Barcelona.

The idea was to create a virtual environment where users could choose an avatar, explore a pixel-art city, and interact with different spaces.

The project focuses on front-end development, interactive interfaces, and exploring how virtual environments can support social interaction.

## Features

- **Avatar Selection:** Users can choose their avatar before entering the city.
- **Personalized Entry:** A welcome screen collects basic user information.
- **Interactive City:** A pixel-art environment with clickable buildings and animated elements.
- **Navigation:** JavaScript-based interactions allow users to explore different areas.
- **Message Board Prototype:** A simple interface where users can enter and display messages locally.
- **Custom Design:** Pixel-art graphics, CSS animations, and interactive visual elements.

## Project Structure

- `index.html` — Welcome screen, avatar selection, and city environment
- `main.js` — User interactions and navigation logic
- `style.css` — Main interface styling
- `page3.html` — Message-board prototype
- `style-secrets.css` — Message-board styling
- `img/` — Avatars and visual assets
- `sillyclient.js` — Third-party networking library included for experimentation

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Choose an avatar and enter the virtual city.
4. Explore the available interactive elements.

No backend installation is required for the existing prototype.

## Limitations

This is an academic prototype rather than a finished communication platform.

- Real-time communication between users is not implemented.
- Some navigation destinations remain incomplete.
- Messages are displayed locally and are not stored or transmitted.
- Input handling and validation need further improvement before public deployment.

## Academic Context

Developed as a collaborative project during the Erasmus+ exchange programme at **Universitat Pompeu Fabra, Barcelona (2024–2025)**.

The project provided an opportunity to apply front-end development concepts while experimenting with interactive virtual environments.
